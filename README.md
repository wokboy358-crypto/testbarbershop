# Бот записи в барбершоп — инструкция по запуску

Бот умеет:
- принимать запись клиента (услуга → мастер → дата → время → подтверждение);
- показывать только свободные слоты времени;
- присылать вам уведомление о каждой новой записи и об отмене;
- показывать клиенту его записи и позволять их отменить.

Один мастер уже настроен. Если появится второй — просто допишите его имя в `config.py`, бот сам добавит шаг выбора мастера.

---

## Шаг 1. Получите токен бота у BotFather

1. Откройте Telegram, найдите бота **@BotFather**.
2. Отправьте команду `/newbot`.
3. Придумайте имя бота (например, "Барбершоп Ростов") и username, оканчивающийся на `bot` (например, `rostov_barber_bot`).
4. BotFather пришлёт токен — длинную строку вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`. Сохраните его, он понадобится ниже.

## Шаг 2. Узнайте свой Telegram ID (это будет ADMIN_ID)

1. Найдите в Telegram бота **@userinfobot**.
2. Нажмите Start — он пришлёт ваш числовой ID. Сохраните его.

## Шаг 3. Арендуйте VPS

Подойдёт любой провайдер (Timeweb, Selectel, Beget, Hetzner и т.д.) с образом **Ubuntu 22.04** или новее. Минимальная конфигурация (1 CPU, 1 ГБ RAM) более чем достаточна. После оформления вы получите:
- IP-адрес сервера (например, `95.163.xxx.xxx`);
- логин (обычно `root`);
- пароль или SSH-ключ.

## Шаг 4. Подключитесь к серверу по SSH из PowerShell

SSH — это защищённое подключение к удалённому серверу через терминал. В Windows 10/11 он уже встроен в PowerShell, ничего дополнительно ставить не нужно.

1. Откройте **PowerShell**.
2. Введите (замените IP на ваш):
   ```powershell
   ssh root@95.163.xxx.xxx
   ```
3. При первом подключении спросит "Are you sure you want to continue connecting?" — введите `yes` и нажмите Enter.
4. Введите пароль от сервера (при вводе пароль не отображается на экране — это нормально, просто печатайте и жмите Enter).
5. Если всё получилось, приглашение в PowerShell изменится на что-то вроде `root@server:~#` — вы внутри сервера.

## Шаг 5. Установите Python и нужные инструменты на сервере

В том же окне SSH-подключения выполните по очереди (каждую строку — Enter, дождаться завершения):

```bash
apt update
apt install -y python3 python3-venv python3-pip unzip
```

## Шаг 6. Загрузите файлы бота на сервер

Проще всего — с вашего компьютера через `scp` (тоже входит в Windows). Файлы бота вы получите от Claude одним zip-архивом.

1. Скачайте архив с ботом на свой компьютер (например, в папку `Загрузки`).
2. Откройте **новое** окно PowerShell (SSH-окно не закрывайте) на своём компьютере и выполните (замените путь и IP на свои):
   ```powershell
   scp $HOME\Downloads\barbershop-bot.zip root@95.163.xxx.xxx:/root/
   ```
3. Введите пароль от сервера ещё раз.
4. Вернитесь в окно с SSH-подключением к серверу и распакуйте архив:
   ```bash
   cd /root
   unzip barbershop-bot.zip -d barbershop-bot
   cd barbershop-bot
   ```
   (если файлы распаковались не во вложенную папку, а прямо в `/root`, скорректируйте команду `cd` по факту)

## Шаг 7. Установите зависимости бота

Всё ещё в SSH-окне, внутри папки `barbershop-bot`:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Если всё прошло без красных ошибок — зависимости установлены.

## Шаг 8. Настройте токен и ID администратора

```bash
cp .env.example .env
nano .env
```

Откроется текстовый редактор `nano` прямо в терминале:
1. Стрелками перейдите к строке `BOT_TOKEN=...` и замените текст после `=` на ваш токен из Шага 1.
2. Так же впишите ваш `ADMIN_ID` из Шага 2.
3. Сохраните: `Ctrl+O`, затем Enter. Выйдите: `Ctrl+X`.

## Шаг 9. Проверьте, что бот запускается

```bash
python bot.py
```

В терминале должно появиться `Бот запущен`. Откройте вашего бота в Telegram и отправьте `/start` — должно прийти меню. Если работает, остановите бот сочетанием `Ctrl+C` — дальше настроим его постоянную работу.

## Шаг 10. Настройте автозапуск (чтобы бот работал 24/7)

1. Выйдите из виртуального окружения: `deactivate`
2. Скопируйте сервисный файл в системную папку:
   ```bash
   cp barbershop-bot.service /etc/systemd/system/barbershop-bot@root.service
   ```
3. Запустите и включите автозапуск:
   ```bash
   systemctl daemon-reload
   systemctl enable barbershop-bot@root
   systemctl start barbershop-bot@root
   ```
4. Проверьте статус:
   ```bash
   systemctl status barbershop-bot@root
   ```
   Должно быть написано `active (running)` зелёным. Нажмите `q`, чтобы выйти из просмотра статуса.

Теперь бот будет работать постоянно и сам перезапустится, если сервер перезагрузится.

## Как посмотреть логи бота

```bash
journalctl -u barbershop-bot@root -f
```
(`Ctrl+C` — чтобы выйти из просмотра)

## Как изменить услуги, цены или часы работы

На сервере откройте файл конфигурации:
```bash
cd /root/barbershop-bot
nano config.py
```
Отредактируйте список `SERVICES` (услуга, цена, длительность в минутах) или `WORK_START_HOUR` / `WORK_END_HOUR`. Сохраните (`Ctrl+O`, Enter, `Ctrl+X`), затем перезапустите бота, чтобы изменения применились:
```bash
systemctl restart barbershop-bot@root
```

## Как добавить второго мастера

В `config.py` в списке `MASTERS` допишите ещё одно имя:
```python
MASTERS = [
    "Мастер",
    "Имя второго мастера",
]
```
Бот автоматически покажет шаг выбора мастера, как только их станет больше одного. Не забудьте `systemctl restart barbershop-bot@root`.

Если что-то не запускается — скопируйте текст ошибки из терминала и пришлите её сюда, разберём вместе.
